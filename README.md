1. Abrir esta pasta no VS Code.
2. Abrir `index.html` com o Live Server.

## Vídeos

- Vídeo principal da homepage: `assets/video/academia-workout-hero.mp4`
- Vídeo de drone da secção “Conhece o espaço por inteiro”: `assets/video/academia-workout-drone.mp4`
